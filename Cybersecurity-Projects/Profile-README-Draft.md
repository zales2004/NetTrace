## In Progress: AegisTrace

An evidence-grounded AI SOC project intended to correlate security events into timelines, distinguish observed facts from hypotheses, map supported behavior to MITRE ATT&CK, and recommend defensive actions. Features will be described as completed only after implementation and testing.

## Investigation Principles

1. Collect relevant telemetry and preserve evidence.
2. Build timelines and correlate events across systems.
3. Separate directly observed facts from analyst hypotheses.
4. Record limitations, false-positive cases, and validation results.
5. Test only in authorized environments.
